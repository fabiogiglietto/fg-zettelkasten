# Computational Text Analysis & LLMs

Methodological work on using large language models and embedding models for classification, annotation and clustering of political and social media text, including validation challenges of 'LLMs-in-the-loop' pipelines. An active methodological frontier connected to PhD-level data analysis teaching and recent AoIR/Sociologica papers.
