# Computational Methods & LLM-Assisted Content Analysis

Methodological work on applying computational social science tools—embedding models, LLMs-in-the-loop pipelines, human-machine annotation validation—to large-scale text and network data in communication research, underpinning both teaching (Digital Social Network Analysis, Data Analysis for Media Studies) and recent AoIR collaborations.
